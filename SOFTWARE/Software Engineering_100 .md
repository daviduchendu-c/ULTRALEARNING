- Foundations: CS50 + MIT OCW computer-science lectures.

- DSA: MIT algorithms lectures plus implementation/problem practice.
- Web: MDN first; supplement with focused HTML/CSS/JS videos.
- React: React official documentation first; supplement with project videos.
- Systems/cloud: university systems lectures and official vendor/container documentation.
